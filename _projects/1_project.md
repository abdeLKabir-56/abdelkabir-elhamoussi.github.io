## Marketify

Marketify is a full-stack e-commerce project I built to work with a
microservice-based architecture.

The main goal was to separate the application into independent services
and make the different parts communicate through APIs.

### Technologies

- Java
- Spring Boot
- Angular
- MySQL
- Docker
- REST APIs
- Microservices

### What I worked on

I worked on the backend with **Spring Boot**, designing the different
services and their REST APIs.

On the frontend, I used **Angular** to build the user interface and
communicate with the backend services.

The application uses **MySQL** for data persistence and **Docker** to
containerize the different parts of the application.

One of the parts of the project was also integrating a secure payment
flow and handling communication between the different services.

### Architecture

The application is organized around several services rather than having
everything inside a single backend.

This allowed me to work with the main concepts of microservice
architecture, including service communication, API design and
independent application components.
